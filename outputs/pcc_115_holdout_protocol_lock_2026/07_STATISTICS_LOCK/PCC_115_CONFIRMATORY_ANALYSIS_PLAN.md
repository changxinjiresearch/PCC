# Confirmatory analysis plan

All inference is patient-level. Report paired mean/median differences, Wilcoxon p-values with Holm adjustment, 95% paired bootstrap intervals, Cohen's dz, rank-biserial effect size, and wins/ties/losses. Zero differences, all-zero maps, empty predictions/targets, and non-finite values are handled by a predeclared deterministic policy; no result-dependent exclusions are allowed. No 115-case statistics are present.
