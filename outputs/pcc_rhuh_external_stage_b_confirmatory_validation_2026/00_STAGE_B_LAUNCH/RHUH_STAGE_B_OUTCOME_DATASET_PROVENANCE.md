# RHUH Stage B outcome-only dataset provenance

The dataset contains byte-for-byte copies of the locked early-postoperative and recurrence segmentation files for the 39-case confirmatory cohort, plus authority manifests and policies. No NIfTI voxel array was opened while building this dataset; no target or performance was computed. It contains no T1ce image, preoperative image, checkpoint, training data, P0, or result file.
